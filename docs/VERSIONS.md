# Versões e downloads

As versões compiladas ficam na aba **Releases** do repositório:

https://github.com/arthurguedesribeiro02-dev/WinJalBionic_Cmod/releases

## WinJalCMOD_13.0.1

A release `WinJalCMOD_13.0.1` publica os APKs gerados pelo workflow do GitHub Actions, incluindo as variantes Ludashi e Vanilla, além de `SHA256SUMS.txt`.

A identidade visual WinJalLator rosa, brilhante e prateada é preservada. Os APKs são compilados pelo workflow; nenhum APK de terceiro é renomeado ou anexado artificialmente.

## Como gerar uma nova versão

1. Abra **Actions → Build and Release APK**.
2. Clique em **Run workflow**.
3. Informe a tag da versão, por exemplo `WinJalCMOD_13.0.1`.
4. Escolha se será pre-release.
5. Aguarde o build terminar.
6. Abra a aba **Releases** e baixe os APKs e `SHA256SUMS.txt`.

Use o checksum para verificar a integridade antes de instalar.
